梳理展示端和管理端的数据逻辑（基于最终版代码）：

需要把整个页面的所有模块梳理一遍：全局卡片、图表、各列表。

区分的核心维度：

时间点：当前、当天、未来 N 天。

时间范围：累计、活跃、特定日期、最近 N 天。

统计对象：本金 (amount)、收益 (profit)、本金+收益 (total)。

过滤规则：状态（质押中、已赎回、已复投）。

逐模块梳理：

第一排卡片（总质押、活跃质押、15/30天周期）：

总质押：全历史订单（包括已赎回、已复投、质押中）的本金总和。无论时间，只要上过链。

活跃质押：当前状态为“质押中”且未解锁（或包含已到期未赎回？代码里 calcStatsFromRecords 里的 activeStaked 是 status === 1，包含了未到期的和到期未赎回的）。

15/30天周期：当前活跃订单中，属于15天产品或30天产品的本金。

第二排卡片（2/7/15天内到期、LP池余额）：

2/7/15天内到期：当前活跃订单中，解锁时间在未来的 2/7/15 天内的本金+收益总和。注意：已过期但未赎回的订单，因为 remain <= 0，通常也会被计入 <= DURATION_2 里（代码逻辑：if (remain <= DURATION_2) stats.unlock2d += amt;。所以已到期未赎回的也会包含在内）。

LP池余额：实时链上 LP Pair 合约里的 UUSD 数量（或云端定时同步的数量）。

第三排卡片（直接质押、复投质押、泡沫、覆盖率）：

直接质押：当前活跃订单中，previousOrderId === 0（没有前置订单，即首次直接质押）的本金。

复投质押：当前活跃订单中，previousOrderId > 0（由之前的订单复投而来）的本金。

泡沫：活跃质押本金 / LP池余额。

覆盖率：LP池余额 / 活跃质押本金 * 100%。

图表（图表 Tab）：

每日地址趋势：默认 30 天，X 轴是日期。按“新增/活跃”地址统计（当天第一次建单为新增，当天有活跃未赎回订单算作活跃）。

每日趋势（新增/活跃/复投/赎回）：默认 120 天。按每天新增订单、状态为活跃、复投、赎回的本金统计。

到期分布（本金+收益堆叠）：统计当前活跃订单，按剩余到期时间分段（已到期、0-3天、3-6天等）。

未来每日到期（本金+收益）：统计当前活跃订单，按解锁日期在未来 30 天内的分布。

未来30天每日到期记录：同上的表格版。

排行榜（前500）：对当前活跃订单按地址汇总本金进行排名。

每日统计（Tab）：

显示最近 30 天的数据，按“质押时间”归到哪一天。包含新增、活跃、15/30天周期、复投、赎回的本金。

质押记录（Tab）：

只有状态为“质押中”的订单（queryResults 通常只存放活跃状态的数据，或者全部数据，具体看后台逻辑。但在管理端，queryResults 是 isActive 过滤后的。用户前端过滤按 date 是 filter 了 stakeTime，也就是建单时间）。默认选中今天，只显示今天建单的记录。

这里有一个细节，管理端默认筛选今天，展示端默认筛选今天。

每天进出多少钱（Tab）：

日期选择器：仅控制上方的 4 个卡片（入金、出金、净额、本金复投）。选哪天就是哪天的数据。

范围下拉框（最近30天/90天/全部）：控制下方的图表和表格。

入金：订单的建单时间（stakeTime），本金。

出金：状态为已赎回（2），赎回时间（redeemedAt 或 unlockTime），本金+收益。

本金复投：状态为已复投（3），复投时间，本金。

奖励领取：已赎回订单的收益部分。

赎回记录（Tab）：

状态为“已赎回”（status=2）的订单。默认选中今天，显示今天赎回的记录。可按日期/地址搜索。

复投记录（Tab）：

到期未赎回（Tab）：

### 一、 全局数据卡片（页面最上方）
*数据实时根据链上或云端返回的最新数据计算，不受页面上的日期筛选影响。*

1. **总质押(本金)**：历史累计，包含**所有**订单（质押中、已赎回、已复投）的本金总和。
2. **活跃质押(本金)**：当前状态为“质押中”的所有订单本金总和（**包含已经到期但尚未赎回的订单**）。
3. **15天/30天周期(本金)**：当前处于“质押中”状态，且分别属于15天产品和30天产品的本金总和。
4. **2天内/7天内/15天内到期(本金+收益)**：针对当前“质押中”的订单，计算距离解锁时间小于等于 2天/7天/15天 的本金+收益。**注意：如果已经过了解锁时间但还没赎回，也会算在这个数据里。**
5. **LP池余额**：实时读取的 PancakeSwap 等 DEX 的 LP 池里的 UUSD 储备量。
6. **直接质押**：当前活跃订单中，`previousOrderId = 0`（即没有前置订单，直接从钱包打进合约的首次质押）的本金。
7. **复投质押**：当前活跃订单中，`previousOrderId > 0`（即通过上一个订单到期复投而来的）的本金。
8. **泡沫**：计算公式 `活跃质押本金 ÷ LP池余额`。
9. **覆盖率**：计算公式 `LP池余额 ÷ 活跃质押本金 × 100%`。

### 二、 📊 图表 Tab
*图表主要受各个卡片右上角的“7天/30天/90天/120天”按钮控制。*

1. **每日地址趋势 (活跃/新增)**：X轴是日期。**新增**是指当天（以北京时间8点为界）建单的独立地址数；**活跃**是指当天有未赎回订单的独立地址数。
2. **每日趋势 (新增/活跃/复投/赎回)**：X轴是日期，Y轴是**本金**。
   * 新增：按 `stakeTime` 算；
   * 活跃：当天建单且目前还在质押中的本金；
   * 复投/赎回：当天发生复投或赎回动作的订单本金。
3. **到期分布 (本金+收益)**：针对当前活跃订单，按**剩余时间**分段（已到期、0-3天、3-6天...）。
4. **未来每日到期 (本金+收益)**：以“今天”为起点，未来30天内每天到期的本金和收益分布。
5. **未来30天每日到期记录**：上方图表的明细数据版。
6. **前500质押金额排行榜**：对当前**活跃订单**按地址汇总本金进行从高到低排序。

### 四、 📋 质押记录 Tab
*页面默认选中“今天”，为了防止几万条数据一次渲染导致卡顿。*

* 只展示**当前活跃（状态为1：质押中）**的订单。
* **时间筛选**：过滤的是订单的**质押时间（stakeTime）**，即订单是在哪一天建的。如果你选“今天”，它就只显示今天建单的记录。

### 五、 💰 每天进出多少钱 Tab
*这个面板做了特殊的分离控制逻辑：*

1. **4个统计卡片（入金/出金/净额/复投）**：
   * 受**左侧的日期选择器**控制。
   * 如果你选了某一天，就只显示那一天的金额；如果你把日期清空，它就显示右侧下拉框（最近30天/90天/全部）范围内所有数据的加总。
2. **下方的柱状图和表格**：
   * **只受右侧的范围下拉框（最近30天/90天/全部）控制**。
   * 不受日期选择器影响，始终展示对应范围内的每一天明细。
   * **交互联动**：如果你点击了柱状图上的某一天柱子，左侧的日期选择器会自动跳到那一天，并且上方卡片的数据也会同步变成那一天的。
3. **数据计算口径**：
   * **实际入金**：按 `stakeTime` 算，即建单的时间，统计本金。
   * **实际出金**：按 `redeemedAt`（赎回时间）算，统计本金+收益。
   * **本金复投**：按复投动作发生的时间，统计本金。
   * **奖励领取**：出金中包含的收益部分。

---

### 六、 💸 赎回记录 / 🔁 复投记录 / ⚠️ 到期未赎回
*默认选中今天。*

1. **赎回记录**：只显示状态为“已赎回”的订单。**日期筛选**过滤的是**赎回时间**（哪一天操作的赎回）。
2. **复投记录**：只显示状态为“已复投”的订单。**日期筛选**过滤的是**复投时间**（哪一天操作的复投）。
3. **到期未赎回**：显示所有**当前状态还是“质押中”，但 unlockTime 已经小于了当前时间**的订单。计算它的逾期时长（`当前时间 - unlockTime`）。
